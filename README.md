# Python File Handling – Notes Management Program

## Project Description
This project demonstrates Python's built-in file handling capabilities through a simple Notes Management Program. It creates, reads, writes, and appends information to a text file named `notes.txt`.

## Operations Performed
- Create a text file using `open()`.
- Write at least 10 lines into the file.
- Read the entire file using `read()`.
- Read a specific number of characters.
- Read individual lines using `readline()`.
- Read all lines using `readlines()`.
- Append additional notes without deleting existing content.
- Reopen and display updated file contents.
- Demonstrate file modes: `r`, `w`, and `a`.
- Open and close files manually using `close()`.
- Use `with open()` for automatic file closing.

## Technologies Used

## File Generated

## Key Learning
Understand Python file handling operations and why the `with open()` statement is preferred for safely managing files.
